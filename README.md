# Имитационная модель детского спортивного комплекса

## О проекте

Проект посвящён разработке и исследованию имитационной модели работы детского спортивного комплекса.

Модель позволяет исследовать процессы обслуживания посетителей, работу ресепшена, распределение нагрузки между спортивными направлениями и влияние интенсивности входного потока на показатели системы.

Проект выполнен в среде AnyLogic с использованием дискретно-событийного моделирования и пространственной 2D/3D-визуализации.

---

## Цель проекта

Разработать модель спортивного комплекса для анализа:

- загруженности системы;
- работы ресепшена;
- распределения посетителей по направлениям;
- накопленного дохода;
- максимального количества посетителей внутри комплекса.

---

## Описание предметной области

Рассматривается один рабочий день детского спортивного комплекса.

Основной сценарий:

1. Ребёнок приходит вместе с родителем.
2. Посетители проходят ресепшен.
3. Выполняется оплата разового занятия, покупка абонемента или проверка действующего абонемента.
4. Ребёнок выбирает направление:
   - карате;
   - гимнастика;
   - танцы.
5. После занятия ребёнок и родитель покидают систему.

## Основные компоненты модели

В модели реализованы:

- поток посетителей;
- очередь на ресепшене;
- обслуживание клиентов;
- система оплаты;
- распределение по спортивным направлениям;
- моделирование длительности занятий;
- учёт загрузки помещений.

---

## Анализируемые показатели

Для оценки работы системы используются:

- количество посетителей;
- посещаемость спортивных направлений;
- количество проданных абонементов;
- количество разовых оплат;
- накопленный доход;
- текущая загрузка комплекса;
- максимальное количество людей внутри системы.

---

## Сценарный эксперимент

Проведён анализ влияния интенсивности входного потока посетителей.

Изменяемый параметр:

`arrivalInterval`

Рассмотрены сценарии:

- низкая нагрузка;
- базовая нагрузка;
- высокая нагрузка.

Эксперимент позволяет оценить изменение:

- длины очередей;
- количества посетителей;
- дохода;
- загрузки комплекса.

---

## Результат проекта

Разработана имитационная модель детского спортивного комплекса, включающая:

- 2D-план помещений;
- 3D-визуализацию;
- графики показателей;
- сценарный анализ.

Модель может использоваться для оценки эффективности работы системы и поиска узких мест в процессе обслуживания посетителей.
